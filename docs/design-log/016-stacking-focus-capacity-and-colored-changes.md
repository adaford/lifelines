# Stacking focus capacity and colored changes (11 November 2026)

Parent year-review changes and event stat outcomes use green for increases, red for decreases, and neutral text for unchanged displayed values. Event choices, completed reviews, and the journal share this presentation. Saved prose and rating endpoints are never rewritten.

New event restrictions use signed `focusCapacity` changes rather than absolute caps: two -1 effects subtract 2 from the focus's normal maximum. Positive capacity offsets negative capacity, within the existing 4-point core or 2-point school-activity scale. Perk/legacy caps and enrollment eligibility remain hard limits. Repeated capacity or minimum effects create separate instances with independent expiry; distinct effects also sum. Legacy saved absolute caps, temporary stat modifiers, and total-budget `focusPoints` retain their existing behavior.

New `focusMinimums` effects add required points. Effective minima are limited by capacity, enrollment, and the available budget, in stable focus-key order if demands conflict. On receipt or changed eligibility, move only the necessary points from allocations above their minima. Controls and progression enforce the same constraints; expiry does not refill allocations. Minimums and capacities are shown as signed integer changes with their source and duration. Schema 20 accepts both optional stage-specific fields without migrating existing saves or changing RNG on load. Historical reviews retain their original decisions.
